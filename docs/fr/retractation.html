Se rétracter du contrat

Si vous souhaitez annuler votre achat, voici comment faire.

Mis à jour le 30 octobre 2026

Pour vous rétracter de votre achat, remplissez le formulaire en ligne puis confirmez : vous recevez aussitôt un accusé de réception par e-mail, avec le contenu, la date et l'heure de votre demande. Vous pouvez aussi nous écrire avec le modèle ci-dessous.

Remplir le formulaire de rétractation

Formulaire de rétractation

À l'attention de [PRÉNOM NOM], [ADRESSE], contact@algoclair.example :
Je vous notifie par la présente ma rétractation du contrat portant sur le guide numérique ci-dessous :
– N° de commande : …
– Commandé le : …
– Nom : …
– E-mail utilisé pour la commande : …
– Date : …

Bon à savoir

Lors de l'achat, vous avez demandé l'accès immédiat au guide et reconnu perdre votre droit de rétractation (article L.221-28 13° du Code de la consommation). Si vous n'avez pas encore pu accéder aux fichiers, ou en cas de problème avec le guide, écrivez-nous quand même : nous examinons chaque demande, et la garantie légale de conformité s'applique dans tous les cas.
